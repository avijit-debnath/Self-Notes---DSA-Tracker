# Self-Notes---DSA-Tracker

> **SelfNote** is a personal Data Structures & Algorithms (DSA) tracker and notebook desktop application built with **Electron**, **React**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

- 🌳 **Hierarchical Topic Tree**: Organize questions by topics, patterns, and sub-branches with infinite nesting.
- 📝 **Rich Problem Editor**: Track problem statements, multiple solution approaches, code snippets, and time/space complexity analysis.
- 🎙️ **Voice Notes & Verbal Walkthroughs**: Record voice notes and verbal explanations with real-time seekable progress trackers, `-5s` rewind, and `+5s` fast-forward controls.
- 📸 **Photo Notes**: Attach and inspect whiteboard diagrams, handwritten notes, and solution screenshots.
- ⚡ **DSA Problem Importer**: Quickly import problem details directly from LeetCode, GeeksforGeeks, Codeforces, and HackerRank.
- 💾 **Offline-First SQLite Database**: Powered by `sql.js` with local persistence on your machine.
- 🔄 **Backup & Export**: Full `.zip` archive export/import and optional GitHub sync backup.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/avijit-debnath/Self-Notes---DSA-Tracker.git

# Navigate to project directory
cd Self-Notes---DSA-Tracker

# Install dependencies
npm install
```

### Running Locally (Development Mode)
```bash
# Run both Vite dev server and Electron desktop app
npm run electron:dev
```

### Production Build
```bash
npm run build
```

## 🛠️ Tech Stack
- **Desktop Runtime**: Electron
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **State Management**: Zustand
- **Icons**: Lucide React
- **Database**: SQLite (sql.js)
- **Bundler**: Vite
